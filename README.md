# datsrice

A Vite + React app for showing collection of @datsfilipe's unix customization screenshots.

### Deploy

Explore the rices at: [datsrice.datsfilipe.xyz](https://datsrice.datsfilipe.xyz)

### Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS

### Setup

```bash
bun install
bun run dev
```
